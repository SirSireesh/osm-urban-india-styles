# OSM Urban India Map Styles

This repo contains styles for [OSM Urban India](http://github.com/sirSireesh/osm-urban-india) map tiles

## Styles

There are two styles, urban and urban-dark. Urban started off as a minor edit of OpenFreeMap's 'liberty' style, but has since diverged a lot.

## Sprites

The sprite is built from source SVGs kept under `styles/urban/` (see
`sprites/create_sprites.sh`). Icons come from Mapbox Maki, osm-liberty and
osm-bright; the India National Highway shield blanks are from
[openstreetmap-americana](https://github.com/osm-americana/openstreetmap-americana),
with the National Expressway variants recolored locally. Per-icon licensing
and provenance: [sprites/LICENSE.md](sprites/LICENSE.md).
